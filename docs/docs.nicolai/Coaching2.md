## Coaching Samenwerking, Planning en User Story's 

**Samenwerking**
De samenwerking tussen ons had een intressante shift na het eerste gesprek we werden allemaal wat rustiger in ons werk en we hadden wat meer vertrouwen in elkaar en in de kwaliteiten die we hadden. Ik heb zelf ook een stuk minder de leider rol overgenomen en liet mijn teamgenoten een stuk meer hun gang gaan en wat bleek is dat dit een stuk beter werkte we hebben deze periode veel werk geleverd en ook veel geleerd individueel maar ook als een team. Hiernaast is de manier hoe we met elkaar omgaan verbeterd we hebben een stuk beter op elkaar allergieën ingespeeld en ook veel geleerd over onze eigen. Hulp vragen binnen het team gaat nog steeds erg goed en feedback aan elkaar geven ook hiervoor hebben we zelfs een klein systeem voor gemaakt die werkt als volgt, iemand zet een user story in de verify rij en vervolgens kan alleen een ander teamgenoot deze op closed zetten als de user story helemaal gechekt is en daarna wat feedback heeft gekregen 

**Planning** 
Ik ben altijd matig geweest in plannen dat blijkt nu ook weer maar ik heb een stap hierin gezet. Na de eerste sprint merkte ik dat ik wat minder had gedaan aan planning en dit probleem had ik al vorige twee blokken ook maar nu dacht ik laat ik eens hieraan werken. Ik had een planning gemaakt met de aangemaakte user stories en heb alles een weight gegeven vervolgens heb ik met mijn team elke week een doel gesteld om een bepaalde hoeveelheid van de User Stories af te maken dit werkte erg goed en vervolgens heb ik een stuk meer afgemaakt dan ik zonder planning had gedaan. Naast productief werken heb ik ook doelgericht gewerkt door dit te doen zag ik ook dat ikzelf beter ging werken omdat ik belangerijke dingen afkreeg door prioriteit te geven aan de belangerijkere user stories die we een gewicht hadden gegeven via de poker methodiek.

**User Story's** 
Ik heb ook veel User Story's aangemaakt en die waren niet altijd zo perfect en dit was duidelijk een leerprocess ik zit hier nogsteeds in en zal hier ook nog wel even inzitten omdat ik nog een gedeelte niet goed begrijp maar dat is iets waar ik volgend blok aan wil werken wat vooral bleek is dat ik iets te globaal ben in mijn user story's en dat ik ook wat meer moet doen aan de DoD.
